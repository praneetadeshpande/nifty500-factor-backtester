# Nifty 500 Multi-Factor Screener & Backtester

Python project that ranks Nifty 500 stocks on value, momentum and quality
and backtests the results against the index.

## Status
- [x] Price data pipeline (yfinance -> SQLite), ~500 tickers, 2015-present
- [ ] Fundamentals data
- [ ] Factor calculations
- [ ] Backtester
- [ ] Streamlit dashboard

## Known limitations
- Uses today's Nifty 500 list, so there is survivorship bias.# nifty500-factor-backtester
